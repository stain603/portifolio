## Sobre

Este projeto foi desenvolvido para reunir meus principais trabalhos como desenvolvedor e designer UI/UX em um único lugar.

Além de servir como apresentação profissional, o portfólio demonstra minhas habilidades em desenvolvimento Front-end, Back-end, design de interfaces, criação de componentes reutilizáveis e desenvolvimento de aplicações completas.

O objetivo foi criar uma experiência moderna, rápida, responsiva e com identidade visual própria.

## Instalação

Clone o projeto

```bash
git clone https://github.com/stain603/portifolio.git
```

Entre na pasta

```bash
cd portifolio
```

Instale as dependências

```bash
npm install
```

Execute

```bash
npm run dev
```
